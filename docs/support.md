# Support

PeckBoard is a self-hosted server with companion apps for iPhone, macOS, and
Windows.

## Get Help

- **Documentation** — start with [Getting Started]({{ "/getting-started.html" | relative_url }})
  and [Remote Access]({{ "/remote-access.html" | relative_url }}) (pairing the
  app with your box, connection troubleshooting).
- **Bug reports and questions** — open an issue at
  [github.com/PeckBoard/peckboard/issues](https://github.com/PeckBoard/peckboard/issues).
  Include your box version (Settings → About), the app version, and what you
  expected to happen.

## Common Issues

- **The app can't reach the box** — check the box is running and Remote
  Access is on (Settings → Remote Access). Direct connections work on any
  network; the relayed fallback needs the box registered with its relay
  ([Official Relay]({{ "/remote-access/official-relay.html" | relative_url }})).
- **"This pairing link was already used"** — each device needs its own link;
  create a new one from Remote Access → Add phone.
- **Privacy questions** — see the [Privacy Policy]({{ "/privacy.html" | relative_url }}).
